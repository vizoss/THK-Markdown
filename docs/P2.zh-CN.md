## 验收条件
- 默认文字 15、代码 13；大字体用例修改正文字号到 24，再恢复。字体设置会保存，比较两端前先确认主题及字号一致。
- 窄屏以 Markdown 内容区约 180dp/pt、普通宽度约 340dp/pt 为参照，可使用分屏或改变宿主宽度；仅选择用例不会自动改变屏幕宽度。截图比较需按逻辑单位，不直接比较截图像素。
- 窄屏表格应可横向滚动；文字、引用、列表与代码不得被按钮或边缘遮住。
- 图片使用现有离线 mock：ok.png 约 200ms 后成功，其他地址返回失败，不进行网络请求。成功图为 120×64 逻辑单位。这里不验证真实网络超时。
- 流式长内容：播放→手动上滑→停留历史消息→回到底部→离屏再返回→切换用例。不能抢滚动、串消息、重复输出或保留旧高度。
- Unicode 分片按码点拆分，不拆 UTF-16 代理对；可能暂时切开组合 emoji，完成态必须恢复完整序列。
- 原始历史消息、分片与期望说明都在共享数据中。长内容使用较大分片避免验收等待过久。
- 回归入口检查分片完成态、文本、复制范围、表格数量与目录边界；不替代真实图片异步加载、手动手势、视觉和重启恢复验收。
