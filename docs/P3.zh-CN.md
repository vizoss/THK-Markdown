# P3：提示块、基础脚注、数学公式

共享数据：`ios/Fixtures/data/p3.json`，36 个用例。两端示例均有 P3 分组，上一条/下一条按 P0 → P1 → P2 → P3 连续切换，总计 139 个用例。示例和 Fixtures 不进入 THKMDView 二进制。

## 支持范围

### 提示块（P3-01～08）

```markdown
> [!NOTE]
> 提示内容，可以包含 **强调**、链接、列表和代码。
```

支持大写 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`。标记必须独占顶层引用的第一行。标题独立一行，保留引用的复制、圆角和内边距。未知类型、未完成标记、嵌套在引用/列表内的标记作为普通引用显示。代码内的标记不生效。

### 基础脚注（P3-09～18）

```markdown
正文[^note]，再次引用[^note]。

[^note]: 脚注内容，支持 **行内格式**。
    缩进四个空格继续上一条定义。
```

按正文中第一次引用的顺序生成上标数字，文末分隔线后显示编号定义；重复引用共用编号。定义可在引用之前或之后，重复定义取第一个，未使用的定义不显示，未定义引用保留原文。标签区分大小写，定义只支持顶层，不递归展开脚注中的脚注。

这是基础显示版：**不提供点击跳转、回跳、多级脚注或跨消息引用**；序号不是外部链接。流式定义尚未到达时保留 `[^note]`，到达后重新编号。代码、转义标记与链接地址不触发脚注解析。

### 数学公式（P3-19～36）

```markdown
行内 $E=mc^2$ 或 \(a^2+b^2=c^2\)。

$$
\frac{1}{2}+\sqrt{x}
$$

\[
\begin{pmatrix}a&b\\c&d\end{pmatrix}
\]
```

- 行内支持 `$...$`、`\(...\)`，不跨行；独立块支持顶层单独一行的 `$$` / `\[` 起止定界符；同一行的 `$$...$$` 使用 display 排版。
- 引用、列表、表格单元格中支持行内公式；不将 `math` 代码围栏当公式。独立公式左对齐；宽公式按图片边界等比缩小，不提供横向公式滚动。
- 美元符号紧邻空白、闭合美元符号后紧跟数字时不视为单美元公式，常见 `$20 和 $30` 保持货币文本；需要完全避免歧义时使用 `\$`。
- 使用固定版本 **MathJax 3.2.2 TeX→SVG**，仅启用 base/AMS。支持分式、上下标、根号、求和、积分、矩阵、aligned 等，不承诺完整 LaTeX 文档能力；不支持用户宏定义，避免定义泄漏到下一条消息。
- 禁用动态包加载、HTML/链接扩展和网络资源。输入长度、宏展开、输出尺寸、待处理任务数及缓存均有限制。`\require`、`\href` 等不支持命令回退源码，不执行外部内容。
- 成功结果以透明图片附件加入原生文本，保持行内基线；公式本身不支持按字符选中。加载期间和错误时显示 TeX 源码，未闭合定界符不提前创建图片。图片加载器不会接收到内部公式地址。
- 异步完成时更新布局；消息 reset/复用后取消旧附件更新。缓存键包含源码、字号、颜色与屏幕密度。渲染资源缺失或超时也保留源码。
- 引用块的复制按钮将其中公式还原为 TeX 源码；公式本身不增加单独的复制按钮。

## 主题配置与本地保存

两端字段同名，示例设置面板可调并保存到本地。SDK 本身不强制宿主的保存策略。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `alertNoteColor` | `#0969DA` | NOTE 标题、竖条 |
| `alertTipColor` | `#1A7F37` | TIP 标题、竖条 |
| `alertImportantColor` | `#8250DF` | IMPORTANT 标题、竖条 |
| `alertWarningColor` | `#9A6700` | WARNING 标题、竖条 |
| `alertCautionColor` | `#CF222E` | CAUTION 标题、竖条 |
| `footnoteScale` | `0.75` | 脚注引用相对正文字号的倍率；颜色复用 `linkColor` |
| `mathScale` | `1` | 公式相对正文字号的倍率；颜色复用 `bodyTextColor` |

提示块正文/背景复用 `blockQuoteTextColor` / `blockQuoteBackgroundColor`；标题字号复用正文字号。数学公式背景透明。默认色板不是自动深色模式，宿主应提供适合深色背景的主题。
