# P0：共享 Markdown 验收用例

这一轮只覆盖已发现的高优先级渲染问题及其回归，不包含视频、数学公式、脚注或完整 CommonMark/GFM 一致性认证。

## 唯一数据源

[`ios/Fixtures/data/p0.json`](../ios/Fixtures/data/p0.json) 是 Android、iOS SPM、iOS CocoaPods 测试共同读取的唯一 Markdown 数据源。

- Android sample 将这个目录直接作为 assets；库测试将它直接作为 test resources。
- iOS example 和 SPM 测试通过 `MarkdownFixtures` 开发辅助 product 加载；发布用的 `THKMDView` product 不依赖它。
- CocoaPods test spec 编译同一份模型、打包同一份 JSON，运行同一份共享测试。普通 pod 不包含用例。
- `project.yml` 和已提交的 Xcode 工程均已连接该 product，不需要先生成工程。
- 共享数据改动会触发 Android CI；iOS CI 原有的 `ios/**` 路径规则也会触发。

每条用例有 `id`、标题、类别、适用平台、`markdown`、`chunks`、历史消息 `history`、预期文本片段/复制内容/表格和图表数量，以及人工验收说明。`chunks.joined()` 必须严格等于 `markdown`；三条路径使用同一组分片，不随机切分、不拼入用户输入。`checkpoints` 记录中间态断言，例如 P0-17 在第 1、2 个分片仍为文本，第 3 个分片才成为表格。

## 操作方式

两端示例界面上方提供相同操作：

1. 选择 P0 用例：立即切换到该用例全文，取消上一条播放。
2. 全文：显示最终结果。
3. 播放：从头播放或从暂停处继续，每 500ms 推进一个固定分片。
4. 暂停：停止推进；已提交的分片仍允许完成短暂的渲染防抖和图片加载。
5. 单步：暂停并推进一个分片；全文/播放完成后再次单步会从第一个分片开始。
6. 点击状态栏：查看原文、预期表现与预期复制内容。复制按钮仍复制代码/引用本身。

输入框发送的内容只作为独立用户消息显示，助手播放当前选中的用例，不改变其原文。链接/图片点击会显示 URL 反馈，不跳出示例。

## 回归检查与人工验收

新增测试读取同一 JSON，逐个渲染每个前缀，检查最终文本片段、复制内容、复制范围合法性、表格/图表数量。Android 和 SPM 还在每个分片后推进防抖调度器；SPM 的假调度器现按一次性定时器执行，避免重复执行旧回调。共享 iOS 测试另外断言三级列表实际缩进、代码右侧留位、表格链接回调和图片加载器调用；Android 补充换用例时待执行渲染取消。

视觉要求仍须在设备或模拟器人工验收：

- 默认主题、Vibrant 主题各看一遍 P0-01～09；竖条宽 4、左右间距 8、二级顶部 10dp/pt。
- 复制按钮点击区 32、可见图标 16dp/pt，颜色跟随 `codeTextColor`；嵌套块按钮不能重叠或遮字。
- P0-10 点击链接，再横向滑动表格；P0-11 等待图片完成，立即切换用例，确认不串图。
- P0-16、17 用单步观察每个中间状态，尤其链接右括号、表格分隔行到达时。
- P0-18 播放期间上滑到历史消息、停留、滑回底部；再暂停、单步、切换用例，确认无旧分片落到新消息。

尚未生成或批准截图基线，不能将文字/属性测试通过视为视觉验收通过。本轮代码未运行构建、模拟器或测试，按约定由维护者验证。

## 明确的范围边界

嵌套表格在 P0 统一为 `单元格 | 单元格` 的文本降级；嵌套 Mermaid 统一为代码降级。顶层表格和 Mermaid 保持原生表格/图表显示。CocoaPods 非 1 起始列表编号等其他已知差异不在这 18 个 P0 用例内，也没有宣称已修复。
